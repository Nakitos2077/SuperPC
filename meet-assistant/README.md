# Meet Assistant — Claude поверх Google Meet

Claude сам слушает встречу в Google Meet и подсказывает, что ответить. Ничего вводить не нужно. Подсказки можно видеть в отдельном окне, которого нет на демонстрации экрана.

Состоит из двух частей:

1. **Расширение Chrome** (`dist/`) — слушает Мит и общается с Claude.
2. **Окно-компаньон** (`companion/`) — маленькое окно поверх всех окон. Windows и macOS не отдают его в захват экрана, поэтому на демонстрации и в записи его не видно, видишь только ты.

## Как это работает без твоего участия

- **Слух.** Расширение читает живые субтитры Google Meet. Meet сам распознаёт речь всех участников, включая тебя, а расширение собирает это в расшифровку с именами. Субтитры включаются автоматически и включаются снова, если выключились. Язык распознавания выбирается в настройках субтитров Мита (поставь «Русский»).
- **Авто-режим (включён по умолчанию).** Как только собеседник договорил (пауза примерно 2,5 секунды), новые реплики уходят Claude. Если к тебе обратились, задали вопрос или ждут ответа, Claude сразу выдаёт готовый ответ, который можно сказать вслух. Если от тебя ничего не требуется, он молчит и карточка не появляется.
- **Демонстрация экрана.** Как только ты начинаешь показывать экран, панель внутри Мита полностью убирается со страницы, а после демонстрации возвращается. Подсказки в это время продолжают приходить в окно-компаньон.

## Установка

### 1. Расширение
1. Возьми API-ключ Anthropic: https://console.anthropic.com → API Keys. Запросы оплачиваются по тарифу API.
2. Chrome → `chrome://extensions` → включи **Режим разработчика** → **Загрузить распакованное** → выбери папку `meet-assistant/dist`.
3. Нажми на иконку расширения, вставь ключ. По желанию опиши встречу в поле «Контекст» (например, «собеседование на Senior React»). Нажми **Сохранить**.

### 2. Окно-компаньон (чтобы подсказок не было видно на демонстрации)
1. Установи Node.js LTS: https://nodejs.org
2. Запусти окно:
   - **Windows:** двойной клик по `companion/start-windows.bat`
   - **macOS:** двойной клик по `companion/start-mac.command`
   - или в терминале: `cd companion && npm install && npm start`

   Первый запуск ставит зависимости и занимает около минуты.
3. Когда окно и Мит открыты, на панели в Мите появится значок **🖥 окно**, а в окне — зелёная точка «Подключено».

Окно можно двигать за заголовок, менять размер и прозрачность. `Ctrl+Shift+H` (на Mac `Cmd+Shift+H`) прячет и показывает окно.

## Панель в Мите

Всё работает само, кнопки нужны только при желании:

| Кнопка / клавиша | Что делает |
|---|---|
| ☑ авто | Авто-режим (по умолчанию включён) |
| 💡 Подсказка / `Alt+Q` | Подсказка прямо сейчас |
| 📝 Итоги | Резюме встречи |
| 📸 Экран | Анализ того, что показывают на экране |
| Поле ввода | Свой вопрос |
| 📜 | Расшифровка |
| ▁ / `Alt+M` | Свернуть |

## Сборка расширения из исходников

```bash
cd meet-assistant
npm install
npm run build   # результат в dist/
```

## Устройство

- `src/content.js` — читает субтитры, запускает авто-режим, рисует панель (Shadow DOM).
- `src/page-hook.js` — работает в контексте страницы, замечает начало и конец демонстрации экрана.
- `src/background.js` — вызывает Claude (`@anthropic-ai/sdk`, стриминг), отбрасывает ответы `[SKIP]`, пересылает подсказки в окно-компаньон по `ws://127.0.0.1:47823`.
- `companion/` — Electron-окно с `setContentProtection(true)` (исключение из захвата экрана). Принимает подключения только с локального компьютера и только от расширений Chrome.

## Важно знать

- **Стоимость.** В авто-режиме запрос к Claude уходит после каждой паузы в чужой речи (не чаще раза в 6 секунд). С моделью по умолчанию (Claude Opus 5.5) это заметные деньги за долгий созвон. Если хочется дешевле, выбери в настройках Sonnet 5.5 или Haiku 5.5 и/или уменьши объём расшифровки.
- **Защита от захвата экрана** работает на Windows 10 (версия 2004 и новее) и Windows 11. На macOS свежие версии системы могут её игнорировать при захвате через ScreenCaptureKit. Перед важным созвоном проверь: начни демонстрацию всего экрана и посмотри превью в Мите, видно ли там окно.
- Если показываешь **весь экран** и не запустил окно-компаньон, подсказок не будет видно ни тебе, ни другим: панель в Мите во время показа спрятана. Это поведение отключается в настройках расширения.
- Расширение опирается на разметку субтитров Google Meet. Если Google её поменяет, поиск субтитров может перестать работать, и тогда нужно будет обновить селекторы в `src/content.js`.
- API-ключ хранится только в браузере и отправляется только на `api.anthropic.com`.
- Если по правилам встречи или по закону нужно согласие участников на обработку разговора, предупреди их.

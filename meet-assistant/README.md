# Meet Assistant — Claude поверх Google Meet

Расширение для Chrome. Оно слушает встречу в Google Meet и показывает ответы Claude панелью сверху прямо во вкладке Мита.

## Как оно «слышит» и «видит»

- **Слух.** Расширение читает живые субтитры Google Meet. Meet сам распознаёт речь всех участников, включая тебя, а расширение собирает это в расшифровку с именами говорящих. Субтитры включаются автоматически, а если не получилось — кнопкой **CC** на панели или клавишей `C` в Мите. Язык распознавания выбирается в настройках субтитров Мита.
- **Зрение.** Кнопка **📸 Экран** делает снимок самого крупного видео на странице (обычно это демонстрация экрана) и отправляет его Claude вместе с расшифровкой.

## Что есть на панели

| Кнопка / клавиша | Что делает |
|---|---|
| 💡 Подсказка / `Alt+Q` | Что ответить прямо сейчас на последний вопрос |
| 📝 Итоги | Резюме встречи: решения, задачи, открытые вопросы |
| 📸 Экран | Анализ того, что показывают на экране |
| Поле ввода | Любой свой вопрос по встрече |
| 📜 | Показать или скрыть расшифровку |
| ☐ авто | Сам выдаёт подсказку, когда тебе задают вопрос |
| ▁ / `Alt+M` | Свернуть панель |

Панель можно перетаскивать за заголовок. Её видишь только ты: другие участники её не видят, даже если ты показываешь вкладку (если показываешь весь экран — увидят).

## Установка

1. Нужен API-ключ Anthropic: https://console.anthropic.com → API Keys. Запросы оплачиваются по тарифу API.
2. Chrome → `chrome://extensions` → включи **Режим разработчика** → **Загрузить распакованное** → выбери папку `meet-assistant/dist`.
3. Нажми на иконку расширения, вставь ключ, при желании заполни «Контекст встречи» (например, «это собеседование на позицию X»), нажми **Сохранить**.
4. Открой встречу в Meet — панель появится сверху.

## Сборка из исходников

```bash
cd meet-assistant
npm install
npm run build   # результат в dist/
```

## Устройство

- `src/content.js` — читает субтитры, рисует панель (Shadow DOM), снимает кадр видео.
- `src/background.js` — service worker, вызывает Claude через `@anthropic-ai/sdk` со стримингом и передаёт текст в панель.
- `src/options.js`, `static/options.html` — настройки (ключ, модель, effort, язык, контекст, авто-режим).

По умолчанию используется модель `claude-opus-5-5` с `effort: low`, чтобы подсказки приходили быстро. Модель и effort можно сменить в настройках. Claude получает последние N символов расшифровки (по умолчанию 15 000), это значение тоже настраивается.

## Ограничения

- Расширение опирается на разметку субтитров Google Meet. Если Google её поменяет, поиск субтитров может перестать работать, и тогда нужно будет обновить селекторы в `src/content.js`.
- Субтитры Мита иногда ошибаются в словах и именах. Claude предупреждён об этом.
- API-ключ хранится локально в браузере (`chrome.storage.local`) и отправляется только на `api.anthropic.com`.
- Предупреди участников, если по правилам вашей встречи или по закону нужно согласие на обработку разговора.

# Сохранённые версии Meet Assistant

## physics-version — коммит `4b8cfd6`
Версия «для физики», сохранена по просьбе пользователя 18.11.2026 перед переделкой под программирование.

Что в ней:
- слушает звук встречи (микрофон + собеседники) или субтитры Мита; Google Meet и Zoom в браузере;
- авто-режим (реагирует через ~0,3 с после фразы), строка «услышал / думает»;
- презентации (PDF/PPTX/TXT), строгий режим «только по презентациям», прогрев кэша;
- быстрый режим без «размышлений» (Haiku/Sonnet);
- формулы (LaTeX), рисунки (SVG), кнопка ✏️, определения сначала словами;
- окно-компаньон, невидимое при демонстрации экрана, скрины 📸 / Ctrl+Shift+S / Ctrl+V;
- точный текст ошибки лимита и строка расхода 📊.

Как вернуть (из корня репозитория):
```bash
git checkout 4b8cfd6 -- meet-assistant
git commit -m "Вернуть physics-version"
```

`saved/paste-text-from-chat.patch` — поле «Вставить текст из чата Claude» в настройках.

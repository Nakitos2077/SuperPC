✳ Meet Assistant — настройки

Ключ создаётся на console.anthropic.com → API Keys. Хранится только локально в этом браузере.
«Точно» — Sonnet 5.5 с размышлениями и поиском фактов в интернете: качество близко к чату Claude, ответ обычно за несколько секунд, стоит примерно в 20 раз дороже Haiku. «Быстро» — Haiku 5.5 без размышлений. Кнопка сразу сохраняет настройки.
«Звук» не требует субтитров и бесплатен. Нужен Chrome 135 или новее, иначе слышен только микрофон. Собеседники подписываются «Співрозмовник» (имена знают только субтитры). В Zoom (в браузере) всегда используется «Звук» — субтитров Zoom программа не читает.
Лучше всего PDF: Claude видит слайды целиком — формулы, схемы, картинки. PowerPoint: «Файл → Сохранить как → PDF». Из PPTX берётся только текст. Файлы хранятся только в этом браузере и отправляются вместе с вопросами на api.anthropic.com.
Если ответа в презентациях нет, Claude так и скажет. Без галочки он может дополнять ответ своими знаниями с пометкой «(не из презентаций)».
Больше — лучше контекст длинной встречи, но дороже и медленнее.
Чтобы видеть подсказки во время демонстрации, запусти окно-компаньон (папка companion) — его не видно в трансляции.
  1. В Telegram открой @BotFather → /newbot → придумай имя → скопируй токен вида 123456:ABC....
  2. Вставь токен ниже. Открой своего нового бота и отправь ему /start.
  3. Нажми «Найти мой chat id», потом «Отправить тест» и «Сохранить».
